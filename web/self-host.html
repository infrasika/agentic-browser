Run your own
Agentic Browser.

Run our public Docker images with one configuration file. No source checkout or build is required.

Requires Docker Engine 26+, Compose 2.24.4+, and Bash. Supports Linux amd64/arm64 and Docker Desktop on Apple Silicon.

1. Prepare

curl -fsSL https://agentic-browser.zkpass.org/install.sh | bash
cd agentic-browser

The installer pulls both public images and creates only compose.yaml and .env. It detects Docker socket permissions and does not start the service. No project download is needed.

Inspect the installer or use another directory 
curl -fsSL https://agentic-browser.zkpass.org/install.sh -o install.sh
bash install.sh my-browser

Existing files are never overwritten. Use a new directory for a new installation. The compatibility setup bundle remains available for existing helper-based installations.

2. Configure

Edit .env. The defaults work locally; change the total browser limit to suit your server:

AB_PROJECT_NAME=agentic-browser
AB_PORT=3333
AB_MAX_SESSIONS=1

For a remote team, set AB_PUBLIC_URL=https://browser.example.com and configure an HTTPS reverse proxy. Otherwise, the address defaults to http://127.0.0.1:3333.

Docker Compose reads this .env file when it creates the controller. The dashboard does not change server settings.

Limits and optional settings 
AB_MAX_SESSIONS_PER_MEMBER=1
AB_SESSION_TTL_SECONDS=1800
AB_SESSION_MAX_LIFETIME_SECONDS=14400
# AB_EGRESS_DENY_HOSTS=other-management.example.com

Each member can use one browser by default, within the total limit. The initial lease is 30 minutes; renewals cannot exceed a 4-hour total lifetime. Limits allow 1–32 browsers. See the full guide for supported values.

Only supported settings are passed into the container. For example, AB_PUBLIC_URL becomes PUBLIC_URL. Image digests are fixed in compose.yaml. Keep the project name stable to retain the same data volume.

Apply changes after installation

Edit .env, finish active sessions, then recreate the controller:

docker compose up -d --force-recreate --wait

No image rebuild is needed. A plain restart does not reload these settings. Accounts and saved profiles remain in the data volume.

3. Start and sign in

docker compose up -d --wait
docker compose exec controller npm run members -- create alice

The account command runs inside the image; Node.js and npm are not needed on your host. Enter a password of at least 12 characters. Open http://127.0.0.1:3333 or your configured address, sign in, and create a personal Agent credential. Add a separate member for each teammate.

4. Connect your Agent

Choose where your Agent runs. Replace the installation folder path and personal credential in the configuration, then reconnect your MCP client.

Agent on the same machine

Run pwd in the installation folder to find its full path. Keep the controller running.

  "mcpServers": {
    "agentic-browser": {
      "command": "docker",

      "env": {
        "AGENT_BROWSER_URL": "http://127.0.0.1:3333",
        "AGENT_BROWSER_TOKEN": "YOUR_PERSONAL_AGENT_CREDENTIAL",
        "AGENT_BROWSER_VIEW_URL": "http://127.0.0.1:3333"
      }
    }
  }
}

For local deployments, the API uses internal port 3333; the view URL is the address you open. If you configured a public domain, use that origin for both URLs and ensure the controller can reach it.

Operation and upgrades

Images, storage, and remote access

The controller creates one isolated browser per session from the runtime image, which includes Chrome and both zkPass extensions. Only the trusted controller mounts the Docker socket. Start with one browser; each runtime has a 2 GiB memory and 2 CPU limit, plus service overhead.

Temporary browser data is cleared on close. Saved profiles persist in your private data volume; the server administrator can access that data.

For an Ubuntu website tunnel, run ssh -N -L 3333:127.0.0.1:3333 ubuntu@SERVER_IP. For team access, configure an HTTPS reverse proxy with WebSocket support. Setting the public URL alone does not configure DNS, TLS, or port exposure.

Before upgrading, finish sessions and back up the data volume. Retain your settings and project name. Do not use down --volumes for routine changes. See the full guide for operations and platform notes.
