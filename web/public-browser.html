查看你的 GitHub 私有仓库
你在远程浏览器中登录 GitHub，交还后由 Agent 统计账号下的私有仓库总数，并列出仓库名称。


接入后，把下面的任务发给你的 Agent：
用 agentic-browser 打开 https://github.com/login，把浏览器交给我登录。调用 browser_handoff 后，请先在当前对话中展示返回的实际 humanUrl，包含可点击链接和完整地址，再等待我操作。等我完成登录并交还后，统计我账号下的私有仓库总数，并列出所有私有仓库的名称，完成后关闭会话。
账号、密码和验证码由你在接管的浏览器中输入，无需把密码发给 Agent。


也可以指定公网网页。每个会话使用独立临时浏览器，初始 5 分钟，最多 10 分钟；有并发和频率限额，不保存登录配置。Google、X 等网站可能要求验证或拒绝登录。


公共部署管理员可以管理运行环境；交还后 Agent 可以读取网页内容。请勿分享接管链接或会话密钥。自己的日常业务请部署独立实例。


当前入口为 HTTP，浏览器画面和输入内容未加密。启用 HTTPS 后将显示 GitHub 登录任务；当前请仅使用虚构数据测试连接。
