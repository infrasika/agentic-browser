# 开发与验收计划

当前目标：交付完整 Agent 私有部署；公网继续提供免费 Demo。架构以 [ARCHITECTURE.md](../ARCHITECTURE.md) 为准；不维护外部 MCP 产品或旧安装器的兼容路径。

2026-10-28：用户确认当前服务器和项目用于测试，允许在本机部署和进行故障恢复演练。当前交付先以同机独立 Compose 实例验收推进；独立新主机作为后续兼容性验证，不阻塞本地开发。测试数据与原实例分开，现有备份作为恢复点。

## 已交付功能

- LibreChat 原生浏览器工具、同屏画面、排队、人工接管和自动继续。
- 本地用户、初始 credits、全站每日预算、管理员入口、Turnstile 与 Cloudflare 邮件找回。
- 每账号一个会话、全局硬上限 10、公网实际 5；出口和跨账号隔离。
- 公网健康检查、定时空闲备份、保留 7 份及隔离恢复验收。
- 完整 Agent Compose、一次配置、普通用户创建/重置、TLS SMTP、手动备份、新实例恢复和升级维护流程。
- 固定源码构建、六镜像离线候选包、纯 Python/Docker 安装验收与干净 CI runner 验收工作流。
- Compose 定时空闲备份、忙时重试、完整备份轮转、校验后的目录副本，以及普通备份被强杀后的恢复；实际验收结果见进度文档。

## 已完成的清理与验收

1. 核对 `private.env` 的每个配置用途，只删除无效输入，保持有效密钥和生成配置不变。
2. 移除独立 MCP 入口、旧成员/档案系统、旧网页、旧发布和验收工具；把仍使用的控制状态机放入当前调度模块。
3. 所有开发入口、Dockerfile 和验收都指向当前 Agent；发行清单只接受六镜像格式。
4. TypeScript、配置/调度/接管、打包/备份恢复单元测试以及真实 Chrome、隔离 Compose 和完整候选包验收均通过；具体报告见进度文档。
